Python新特性 match-case 语句

2024-05-31

看了一堆 PEPs 和文章，日常不使用就忘了 😂。看来这个特性不是everyday coding中必用的，不过还是写个笔记再重新理解一下这个特性。

match-case是什么？

match-case本质是Pattern Matching即模式匹配，这概念是从函数式语言如Haskell、Scala、Erlang等中借鉴过来的。一个match表达式包含多个case分支，每个case分支可能包含以下三个部分

  • 模式
  • 可选的if条件
  • 被执行的代码块

match会比较值（即subject）和每个case的模式，直到找到匹配的case，没有则执行默认的case。
初看这个语法，会想到switch-case，进而可能会想到以下类似的 demo

但，这并不是这个特性设计的初衷，它使用场景主要是为了支持destructuring和binding，其实就是unpacking。
